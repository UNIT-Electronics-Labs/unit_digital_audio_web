Get started

  1. Upload a sketch Use I2S/ComputerAudio or PDM/ComputerAudio for the 16 kHz profile. Select the matching profile for SerialStream.
  2. Free the serial port Close the Arduino Serial Monitor and any other app using the port.
  3. Start listening Click Connect and listen, choose the port, and allow browser access.

Before you connect

Use desktop Chrome or Edge on HTTPS or localhost. Audio plays through your default output. RP2040/RP2350 audio has not been verified on hardware.

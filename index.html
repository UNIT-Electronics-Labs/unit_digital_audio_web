How to use it

  1. Upload I2S/ComputerAudio or PDM/ComputerAudio and select the 16 kHz profile. For SerialStream, select the matching profile.
  2. Close the Arduino Serial Monitor and any other app using the port.
  3. Click Connect and listen, choose the port, and grant browser access.

Use a desktop browser with Web Serial support, such as Chrome or Edge, on localhost or HTTPS. Playback uses your default audio output; this page does not create a virtual microphone. RP2040/RP2350 audio has not been verified on hardware.
